# Project Overview

## Project name

Curiosity Quest

## Elevator pitch

A safety-first investigation agent that turns kids' photos, voice, and questions into playful case boards, dynamic puzzles, and parent-aware learning moments.

## Short description

Curiosity Quest helps children explore the world safely. Instead of giving a one-shot answer, Curio turns every question into an investigation with clues, a child-friendly finding, a next mission, and parent safety support when needed.
