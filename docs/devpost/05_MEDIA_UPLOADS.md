1. 7-9 case board with a real image investigation

3. 3-6 Ask screen

## Video demo

The video should show:

- the app actually working
- the problem being solved
- who the project is for
- dynamic AI responses
- photo investigation
- text-only question
- safety/parent layer
- puzzle or badge loop
- AWS usage: Bedrock, Rekognition, Polly, and the agent backend
