- AWS Builder ID email used for the hackathon submission
- AWS account access for the demo backend
- Bedrock model access enabled in the target region
- Preferred AWS region, defaulting to `us-west-2`
- Decision on whether judging demo should run with live Bedrock or deterministic demo mode

## Mobile App

- Target first platform: Android, iOS, or both

- Final app display name: `Curiosity Quest`, `Merakli`, or another name

## Product Demo Content

- One strong historic-place sample image for the main demo
- The exact demo story location if you want it tied to a real place
- Whether the kid demo should use English, Turkish, or bilingual copy
- Parent gate behavior for MVP: simple math gate, PIN, or parent-only demo toggle

## Backend Hosting

- Whether we deploy the backend to AWS App Runner, ECS/Fargate, Lambda container, or a temporary local tunnel for the demo
- Public repository destination for submission
- Whether uploaded demo images may be stored temporarily, or should be processed and deleted immediately
